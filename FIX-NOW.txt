→ Script sẽ collect logs (30 giây)
→ Xem output để hiểu problem:
   • FPS 30-45? → LAG issue (CAS overhead)
   • Flick/stutter? → FLICK issue (TAA blend)

STEP 2: Apply Quick Fix
──────────────────────────────────────────────────────────────────────────────
Chọn 1 trong 3 option:

OPTION A - FIX LAG (nếu thấy FPS thấp):
  Disable CAS để giảm overhead
  
  Mở: native/engine.cpp
  Tìm: bool enableCAS = true;
  Sửa: bool enableCAS = false;

OPTION B - FIX FLICK (nếu thấy flickering):
  Adjust TAA blend để stable hơn
  
  Mở: native/engine.cpp
  Tìm: float taaBlendFactor = 0.08f;
  Sửa: float taaBlendFactor = 0.12f;

OPTION C - FIX BOTH (Nuclear option):
  Disable both TAA + CAS
  
  Mở: native/engine.cpp
  Tìm: bool enableTAA = true;
       bool enableCAS = true;
  Sửa: bool enableTAA = false;
       bool enableCAS = false;

═══════════════════════════════════════════════════════════════════════════════
PARAMETER GUIDE
═══════════════════════════════════════════════════════════════════════════════

TAA Blend Factor (taaBlendFactor):
  0.05  → Very responsive, but may flicker
  0.08  → Balanced (default)
  0.12  → Very stable, may ghosting
  Use: Increase if flicker, decrease if ghosting

CAS Sharpness (casSharpness):
  0.0   → No sharpening (disable)
  0.4   → Light sharpening
  0.6   → Balanced (default)
  0.8   → Heavy sharpening, risk halos
  Use: Decrease if lag, increase if too soft

Enable Flags:
  enableTAA: true/false   (Temporal Anti-Aliasing)
  enableCAS: true/false   (Contrast Adaptive Sharpening)
  Use: Disable either if overhead too high
