CÁCH 1: CÀI QUA SCRIPT (DỄ NHẤT)
═══════════════════════════════════════════════════════════════════════════════

1. Download 2 files (đã share):
   ✓ ThorNativeFG-FG-stability-test.apk
   ✓ CAI-NGAY.bat

2. Kết nối AYN Thor qua USB
   • Settings → Developer Options → USB Debugging = ON
   • Cắm USB-C vào máy tính

3. Double-click: CAI-NGAY.bat
   • Script sẽ tự động cài APK
   • Chấp nhận prompt "Allow USB Debugging" trên Thor nếu có

═══════════════════════════════════════════════════════════════════════════════
CÁCH 2: CÀI THỦ CÔNG QUA ADB
═══════════════════════════════════════════════════════════════════════════════

Trong thư mục: C:\Users\dodan\thor-native-fg

1. Mở PowerShell hoặc CMD

2. Kiểm tra kết nối:
   toolchain\platform-tools\adb.exe devices

3. Cài APK:
   toolchain\platform-tools\adb.exe install -r ThorNativeFG-FG-stability-test.apk

4. Verify:
   toolchain\platform-tools\adb.exe shell pm list packages | findstr thor

═══════════════════════════════════════════════════════════════════════════════
CÁCH 3: CÀI TRỰC TIẾP TRÊN THOR (KHÔNG CẦN MÁY TÍNH)
═══════════════════════════════════════════════════════════════════════════════

1. Download APK về Thor (qua link đã share)

2. Trên Thor:
   • Settings → Security → Allow "Install from unknown sources"

3. Mở File Manager → Downloads → tap vào .apk → Install
