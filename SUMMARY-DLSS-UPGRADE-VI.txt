💡 TECHNICAL HIGHLIGHTS
═══════════════════════════════════════════════════════════════════════════════

1. TAA Implementation:
   • YCoCg color space cho better variance clipping
   • Catmull-Rom 4-tap filter cho history (better than bilinear)
   • Velocity-aware adaptive blending (low motion = more history)
   • Halton sequence sub-pixel jitter (better than fixed patterns)

2. CAS Implementation:
   • Directional edge detection (cross pattern + diagonals)
   • Adaptive strength = f(local contrast, edge factor)
   • Text detection: flat variance + low contrast threshold
   • Neighborhood clamping prevents overshoot/halos

3. Neural Upscaling Enhancements:
   • Gradient-based bounds expansion (15% on strong edges)
   • Perceptual clamping preserves luma first, then chroma
   • Local contrast boost (8%) only on edges, not flat regions
   • Edge detection thresholds tuned for 1080p output

4. Anti-Ringing Improvements:
   • Gradient magnitude = max(gradH, gradV)
   • Expansion factor = clamp(gradient * 3.0) * 0.15
   • Luma preservation: restore original luma if clamping shifts it
   • Per-channel expansion prevents color shifting
